# Application asset provenance

The current `icon-192.png` (192 × 192) and `icon-512.png` (512 × 512) are an original geometric bottle drawing created for this project on October 8, 2026. They can be regenerated with `npm run generate:icons` using the checked-in `scripts/generate-app-icons.mjs`. The generator uses only coordinates, project colors and Node's PNG compression; it does not incorporate a downloaded image, logo, font, reference bitmap or third-party icon. Original-work terms are in the repository LICENSE.

Activity marks are React components from the separately licensed Phosphor/Radix icon packages; their MIT texts are included in THIRD_PARTY_NOTICES.md and third-party-licenses/. The earlier unverified diaper bitmap, icon PNGs and phone/status/keyboard prototype assets were removed from this publication candidate. The application uses browser-native device chrome and input keyboards.
